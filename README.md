# Mpigi Socioeconomic Survey Data

## Overview
This repository contains sample data and a coding book from a community-level socioeconomic survey conducted in **Mpigi District, Uganda**.  
The dataset is used in the *International Development Statistics* project to demonstrate basic data analysis methods for international development research.

---

## Contents
- **Mpigi_codingbook.docx** – Variable names, labels, and coding information.  
- **Mpigi_data_sample.xlsx** – Sample dataset (N = 3,568) including education, economy, religion, gender, and household variables.  
- **README.md** – Project summary and usage information.

---

## Description
The dataset includes information on:
- Gender, marital status, and religion  
- Household economic status  
- Child education expectation (in years)  
- Tuition fees and commuting time  
- Perceived importance of education  

It is designed for learning and teaching basic statistical analysis in R or Python.
